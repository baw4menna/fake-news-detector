# Fake News Detector



## Overview

A web-based tool that detects fake news in Malaysia, built during **ImagineHack Hackathon 2025**.



**My Role**: Frontend Designer & Developer



## Problem Statement

Malaysia faces significant challenges with misinformation spreading rapidly across social media and messaging apps. This tool empowers users to verify news before sharing.



## Tech Stack (My Contribution)



| Layer | Technology |
|-------|------------|
| Frontend UI | Streamlit (Python) |
| Styling | Custom CSS |
| Integration | REST API / direct model calls |



## Features

- Clean, intuitive UI for submitting news articles/text

- Responsive design with custom CSS styling

- Real-time fake news detection results

- User-friendly interface for non-technical users



## How It Works

1. User inputs news article text or URL

2. Backend ML model analyzes the content

3. Results display with detection confidence and bias detection
